# Octo.su Linux x64 / Debian source tree

This folder is the complete Linux-facing application source. It is kept in the repository so Linux changes are visible as normal source changes rather than only inside a ZIP.

Run `scripts/install-linux.sh` for a source checkout, `npm run dist:linux` for the portable/AppImage/Debian build, and `npm run test:native-packaged` plus `npm run test:native-firefox-packaged` for real staged-engine checks.
