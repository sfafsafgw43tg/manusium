GOAL in Browser

Settings stay on this device. Nothing is sent to the developer or anyone else.

Level

A preset sets the options below. Change any option to make your own mix.

Status

    Blocking

    Ads and malware domains

    Blocks requests to the domains in the bundled StevenBlack hosts list. See Lists below.

    Tracker domains

    Blocks requests to a curated set of tracker domains shipped with this extension.

    Fingerprinting scripts

    Blocks requests to known fingerprinting script hosts. It does not change or fake any value a page reads.

    Upgrade to HTTPS

    Loads http:// pages over https:// where possible. Localhost and IP addresses stay on http.

    Link pings and CSP reports

    Blocks ping requests (used for link tracking) and Content-Security-Policy violation reports.

    Third-party scripts

    Blocks scripts loaded from other sites. Many sites will stop working. Use the allowlist for those.

    Third-party frames

    Blocks embedded frames from other sites, such as many ad and video frames.

    Tracking-link cleanup

    Removes click and campaign identifiers such as utm_* and fbclid from addresses you open. Needs access to all sites.

    Cookies and site data

    Block third-party cookies

    A Chrome setting. Sites with an exception, or that use the Storage Access API, may still receive them.

    Clear site data when the browser starts

    Removes cookies, cache and site storage for normal websites at each start. You will be signed out. Installed web apps, history, passwords and downloads are not removed. Best effort.

    Privacy signals and headers

    Send Do Not Track

    Sends DNT: 1. Most sites ignore it.

    Send Global Privacy Control

    Sends Sec-GPC: 1. It is a request only; sites must choose to honour it. Needs access to all sites.

    Referrer

    What other sites learn about the page you came from. The origin-only option needs access to all sites.

    WebRTC IP handling

    Limits which network addresses a page can learn through WebRTC.

    Chrome web services and ad APIs

    Privacy Sandbox ad APIs

    Turns off Topics, Protected Audience (FLEDGE) and ad measurement, where Chrome lets an extension turn them off.

    Hyperlink auditing

    Turns off link ping requests.

    Error-page suggestions

    Error pages will not call web services for suggestions.

    Address-bar search suggestions

    Text you type is not sent to the search provider for suggestions.

    Translation service

    Pages are not sent to Chrome's translation service.

    Network prediction

    Chrome does not pre-connect to sites it predicts you will open.

    Site permissions

    These set Chrome's default for all sites. Whether they override exceptions you already made in Chrome is not verified. Check chrome://settings/content.

    Location
    Notifications

    Toolbar

    Count on toolbar icon

    Shows how many requests were matched on the current tab.

    Site access

    Three options need permission to read and change data on all sites. Chrome shows that warning when you allow it. Protection without these options does not need it.

    Allowlist

    Sites listed here are excluded from blocking, the HTTPS upgrade and tracking-link cleanup. A domain also covers its subdomains. Privacy headers and Chrome settings still apply.

      Custom blocked domains

      Blocks these domains on other sites. Enter one domain per line. Never blocks a page you open directly.

      Lists

        Reset

        Sets every option back to Standard, clears the allowlist and custom list, and removes access to all sites.
